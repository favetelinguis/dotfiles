* Chezmoi
** Local machine config
Use machine-local chezmoi config for machine-specific enablement. The local
config lives outside this repo, normally at =~/.config/chezmoi/chezmoi.toml=.
It is not tracked in git.

This repo is intentionally opt-in. The source state is shared, but
=.chezmoiignore= uses local booleans to decide which targets are active on a
given machine.

** New machine flow
This repo includes =.chezmoi.toml.tmpl=. When you run =chezmoi init= on a new
machine, chezmoi generates an initial local config with everything disabled:

#+begin_src toml
[diff]
exclude = ["scripts"]

[data.apps]
foot = false
fuzzel = false
mako = false
niri = false
swaylock = false
ghostty = false
kak = false
nvim = false
gh_dash = false
tmux = false
kak_task_scripts = false
lf = false
lazygit = false
gitui = false
emacs = false

[data.agent]
codex = false
claude = false
opencode = false

[data.git]
enable = false

[data.github]
globalPrFilter = ""
repoPath = ""

[data.shell]
bash = false
zsh = false
#+end_src

Edit the local config, turn on only what exists on the current machine, then
run =chezmoi apply=.

** Explicit toggles
Everything is controlled directly from local booleans. Nothing is implied by a
profile.

App toggles:
- =apps.foot=
- =apps.fuzzel=
- =apps.mako=
- =apps.niri=
- =apps.swaylock=
- =apps.ghostty=
- =apps.kak=
- =apps.nvim=
- =apps.gh_dash=
- =apps.tmux=
- =apps.kak_task_scripts=
- =apps.lf=
- =apps.lazygit=
- =apps.gitui=
- =apps.emacs=

Agent toggles:
- =agent.codex=
- =agent.claude=
- =agent.opencode=

Git toggles:
- =git.enable=

Shell toggles:
- =shell.bash=
- =shell.zsh=

GitHub machine-local data:
- =github.globalPrFilter=
- =github.repoPath=

Enabling any =agent.*= value installs the shared skills in
=~/.config/agents/skills=. Enabling a specific =agent.*= value also installs
that agent's compatibility symlinks.

Enabling =shell.bash= installs =~/.config/shell/local.sh= and appends a
single guarded source line to =~/.bashrc=. Enabling =shell.zsh= does the same
for =~/.zshrc=. The source line is appended only if it is missing, and
=chezmoi apply= fails if the requested rc file does not already exist.

=git.enable= installs the managed =gh-dash=, =diffnav=, and =delta= config
files and appends a guarded include block to =~/.gitconfig=. The include is
append-only, and =chezmoi apply= fails if =~/.gitconfig= does not already
exist.
=apps.gh_dash= still enables the existing =gh-dash=, =diffnav=, and =delta=
config files, but it does not add the =~/.gitconfig= include hook.
By default this repo sets =[diff].exclude = ["scripts"]=, so =chezmoi diff=
does not show script entries at all. It also does not show the append-only
change to an unmanaged rc file. Use =chezmoi diff --include scripts= if you
want to inspect scripts explicitly.

Examples:

#+begin_src toml
[data.apps]
foot = true
fuzzel = true
mako = true
niri = true
swaylock = true

#+end_src

#+begin_src toml
[diff]
exclude = ["scripts"]

[data.apps]
kak = true
tmux = true
kak_task_scripts = true
ghostty = true
lf = true
lazygit = true
gitui = true

[data.agent]
codex = true
claude = true
opencode = false

[data.git]
enable = true

[data.github]
globalPrFilter = "is:open label:my-label"
repoPath = ""

[data.shell]
bash = true
zsh = false
#+end_src

=github.globalPrFilter= is used by =jrg= to build the global PR search.
=github.repoPath= is used by =jrg= to find the local checkout before handing
off into the same review flow as =jr=. =jrg= searches under =repoPath= for a
matching Git repository up to 4 repo-root levels deep and fails with a clear
error when it finds none or more than one match.

** Agent skills layout
Agent skills are stored once in the canonical shared location:
=~/.config/agents/skills=.

Compatibility paths are managed by chezmoi with per-skill symlinks:
- =~/.claude/skills/<skill-name>=
- =~/.codex/skills/<skill-name>=
- =~/.config/opencode/skills/<skill-name>=

Shared skills are installed when any =agent.*= value is true. Compatibility
symlinks are installed only for the matching =agent.*= value.
